# Documentation de livraison

Ce dossier regroupe les documents de livraison de l’application CesiZen.

## Contenu

- `cahier-de-tests-livraison.md` : cahier de tests couvrant les modules obligatoires et un module facultatif.
- `procedure-validation-recette.md` : procédure de validation et de recette.
- `modele-pv-recette.md` : modèle de procès-verbal de recette.

## Périmètre couvert

Les documents sont rédigés à partir des modules visibles dans l’application :

- **Comptes utilisateurs** : connexion, consultation du compte, modification des informations, changement du mot de passe, suppression du compte.
- **Informations** : consultation des ressources, lecture des articles, création / modification / suppression par un administrateur.
- **Module facultatif choisi** : **tracker d’émotions** : ajout d’une émotion, consultation du journal, suppression, rapport, administration des émotions.
